Quadratic Equations Class 10: 8 Must-Do Board Questions, Solved (CBSE Maths Chapter 4, Discriminant and Word Problems)

Chapter 4 of CBSE Class 10 Maths, Quadratic Equations, is one of the most reliable scoring chapters in the paper. Almost every board question is one of three things: a 1-mark MCQ on roots or the discriminant, a 2-mark "find k" question, or a 3- to 5-mark word problem where you build the equation yourself. Learn the eight types below and very little in this chapter can surprise you.

The rule you must know first

Write the equation as ax² + bx + c = 0 (a ≠ 0) and work out the discriminant D = b² − 4ac.

| Value of D | Nature of roots | |---|---| | D > 0 | Two distinct real roots | | D = 0 | Two equal real roots, each equal to −b/2a | | D < 0 | No real roots |

When D ≥ 0, the roots are x = (−b ± √D) / 2a.

Type 1: A root is given, find the constant (1 mark)

If (1 − p) is a root of x² + px + 1 − p = 0, find its roots. (CBSE Sample Paper 2026-27 pattern)

  • Put x = 1 − p: (1 − p)² + p(1 − p) + (1 − p) = 0.
  • Take (1 − p) common: (1 − p)[(1 − p) + p + 1] = 0, so (1 − p) × 2 = 0 and p = 1.
  • The equation becomes x² + x = 0, so x(x + 1) = 0.
  • Answer: the roots are 0 and −1.

Trap: expanding everything first. Spot the common factor (1 − p) and the question takes four lines. Try it: if x = 2 is a root of x² + kx − 6 = 0, find k. 4 + 2k − 6 = 0, so k = 1.

Type 2: Equal roots, find k (2 marks)

Find k so that 2x² + kx + 8 = 0 has equal roots. For which value are the roots also positive?

  • Equal roots means D = 0: k² − 4(2)(8) = 0, so k² = 64 and k = ±8.
  • Each root is −b/2a = −k/4. For a positive root, k must be negative.
  • Answer: k = ±8; for positive roots k = −8, and the root is 2. Check: 2x² − 8x + 8 = 2(x − 2)².

Trap: writing only k = 8. A square root always gives ±. Try it: for what k does 2x² + kx + 3 = 0 have equal roots? k² = 24, so k = ±2√6.

Type 3: Nature of roots (1 mark)

Find the nature of the roots of 2x² − 4x + 3 = 0.

  • a = 2, b = −4, c = 3, so D = 16 − 24 = −8.
  • Answer: D < 0, so the equation has no real roots.

Trap: a missing term. In 4x² − 5 = 0, b = 0 and c = −5, so D = 0 − 4(4)(−5) = 80, which is positive: two distinct real roots. Students who drop the minus sign on c get the wrong answer. Try it: nature of the roots of 3x² − 2x + 1/3 = 0? D = 4 − 4 = 0: two equal real roots.

Type 4: Equal roots when the equation is hidden (2 marks)

Find p if px(x − 2) + 6 = 0 has two equal roots.

  • Expand first: px² − 2px + 6 = 0.
  • D = (−2p)² − 4(p)(6) = 4p² − 24p = 4p(p − 6) = 0, so p = 0 or p = 6.
  • p = 0 makes the equation 6 = 0, which is not quadratic.
  • Answer: p = 6.

Trap: keeping p = 0. Always check that a ≠ 0. Try it: find k if kx(x − 3) + 9 = 0 has equal roots. 9k² − 36k = 0, so k = 4.

Type 5: Factorisation with surds (2 marks)

Solve x² + 2√2x − 6 = 0 by factorisation.

  • You need two numbers with product −6 and sum 2√2: they are 3√2 and −√2.
  • x² + 3√2x − √2x − 6 = 0, so x(x + 3√2) − √2(x + 3√2) = 0.
  • (x + 3√2)(x − √2) = 0.
  • Answer: x = √2 or x = −3√2.

Trap: hunting only for whole numbers. When b has a √, split it into two surd terms of the same kind. Try it: solve x² − 3√5x + 10 = 0. (x − √5)(x − 2√5) = 0, so x = √5 or 2√5.

Type 6: The quadratic formula (2 marks)

Solve 2x² + x − 4 = 0.

  • a = 2, b = 1, c = −4, so D = 1 + 32 = 33.
  • x = (−1 ± √33) / 4.
  • Answer: x = (−1 + √33)/4 or x = (−1 − √33)/4.

Trap: dividing by 2 instead of 2a = 4. Write "2a = 4" before you substitute. Try it: solve x² − 4x − 1 = 0. D = 20, so x = 2 ± √5.

Type 7: Consecutive integers (3 marks)

The sum of the squares of two consecutive positive integers is 365. Find them.

  • Let the integers be x and x + 1: x² + (x + 1)² = 365.
  • 2x² + 2x − 364 = 0, so x² + x − 182 = 0.
  • (x + 14)(x − 13) = 0, so x = 13 or x = −14. The integers are positive, so x = 13.
  • Answer: 13 and 14. Check: 169 + 196 = 365.

Trap: stopping at x = 13. The question asks for both integers, and you must say why −14 is rejected. Try it: two consecutive negative integers whose squares add up to 481? x² + x − 240 = 0, so x = −16: the integers are −16 and −15.

Type 8: Speed and time (3 to 5 marks)

A train travels 360 km at a uniform speed. If the speed had been 5 km/h more, it would have taken 1 hour less. Find the speed.

  • Let the speed be x km/h. Time = 360/x hours.
  • 360/x − 360/(x + 5) = 1.
  • Multiply by x(x + 5): 360(x + 5) − 360x = x(x + 5), so 1800 = x² + 5x.
  • x² + 5x − 1800 = 0, so (x + 45)(x − 40) = 0.
  • Speed cannot be negative, so x = 40.
  • Answer: 40 km/h. Check: 9 hours at 40 km/h, 8 hours at 45 km/h.

Try it: the altitude of a right triangle is 7 cm less than its base and the hypotenuse is 13 cm. Find the other two sides. x² + (x − 7)² = 169 gives x² − 7x − 60 = 0, so the sides are 12 cm and 5 cm.

One-minute revision

  • Bring every equation to the form ax² + bx + c = 0 before you read off a, b and c.
  • D = b² − 4ac decides everything: two distinct, two equal, or no real roots.
  • "Equal roots" means D = 0, and the root is −b/2a. Remember ± and reject any value that makes a = 0.
  • In word problems, write what x stands for, reject impossible roots in words, and check your answer in the story.

FAQ

Is completing the square in the current syllabus? The rationalised NCERT book focuses on factorisation and the quadratic formula, and completing the square is no longer a separate section. Check your school's syllabus list, but the formula gives every answer you need.

How many marks does this chapter carry? It sits in the Algebra unit of CBSE Class 10 Maths. Expect at least one MCQ or Assertion–Reason on roots, and a word problem or case study in most papers.
