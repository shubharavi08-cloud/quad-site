Chapter 3 of CBSE Class 10 Maths, *Pair of Linear Equations in Two Variables*, gives you two kinds of marks: quick 1-mark questions on **how many solutions** a pair has, and longer word problems where you **build two equations and solve them**. Once you know the ratio test and one clean solving method, almost every board question is one of the eight types below.

## The rule you must know first

Write both equations as a₁x + b₁y + c₁ = 0 and a₂x + b₂y + c₂ = 0, then compare the ratios.

| Ratios | Lines on a graph | Number of solutions | Name |
|---|---|---|---|
| a₁/a₂ ≠ b₁/b₂ | Intersect at one point | Exactly one | Consistent |
| a₁/a₂ = b₁/b₂ ≠ c₁/c₂ | Parallel | None | Inconsistent |
| a₁/a₂ = b₁/b₂ = c₁/c₂ | Coincident (same line) | Infinitely many | Consistent (dependent) |

## Type 1: Infinitely many solutions (1 mark)

> For what value of k do 2x + 3y = 5 and 4x + ky = 10 have infinitely many solutions?

- All three ratios must be equal: 2/4 = 3/k = 5/10.
- 2/4 = 1/2 and 5/10 = 1/2, so 3/k = 1/2.
- **Answer: k = 6.**

**Trap:** checking only a₁/a₂ = b₁/b₂. That condition alone also fits parallel lines (no solution). For "infinitely many", the c ratio must match too. **Try it:** for what k do x + 2y = 3 and 3x + ky = 9 coincide? *1/3 = 2/k = 3/9, so k = 6.*

## Type 2: No solution (1 mark)

> Find k so that kx + 2y = 5 and 3x + y = 1 have no solution.

- Parallel lines: a₁/a₂ = b₁/b₂ ≠ c₁/c₂.
- k/3 = 2/1, so k = 6.
- Check the c ratio: 5/1 = 5, which is not equal to 2. Good.
- **Answer: k = 6.**

**Trap:** forgetting the "≠ c₁/c₂" check. If the c ratio had also been 2, the lines would coincide and there would be infinitely many solutions.

## Type 3: Unique solution (1 mark)

> For which values of k does x + 2y = 3, 5x + ky = 7 have a unique solution?

- Unique means the lines cross: a₁/a₂ ≠ b₁/b₂.
- 1/5 ≠ 2/k, so k ≠ 10.
- **Answer: every real k except 10.**

**Trap:** writing "k = 10". The question asks when the lines are *not* parallel, so the answer is "all values except 10".

## Type 4: Solve by substitution (2 marks)

> Solve x + y = 14 and x − y = 4.

- From the second equation, x = y + 4.
- Substitute: (y + 4) + y = 14, so 2y = 10 and y = 5.
- Then x = 5 + 4 = 9.
- **Answer: x = 9, y = 5.** Check: 9 + 5 = 14 and 9 − 5 = 4.

**Trap:** stopping after finding one variable. Board answers need both values, and a one-line check earns trust from the examiner.

## Type 5: Solve by elimination (2 marks)

> Solve 3x + 4y = 10 and 2x − 2y = 2.

- Multiply the second equation by 2: 4x − 4y = 4.
- Add it to the first: 7x = 14, so x = 2.
- Put x = 2 in 2x − 2y = 2: 4 − 2y = 2, so y = 1.
- **Answer: x = 2, y = 1.** Check: 3(2) + 4(1) = 10.

**Trap:** sign errors when subtracting. If you subtract instead of add, write the whole line with brackets: (3x + 4y) − (4x − 4y).

## Type 6: Age problem (3 marks)

> Five years ago, Nuri was thrice as old as Sonu. Ten years later, Nuri will be twice as old as Sonu. How old are they now?

- Let Nuri's age now be x and Sonu's age be y.
- Five years ago: x − 5 = 3(y − 5), so x − 3y = −10.
- Ten years later: x + 10 = 2(y + 10), so x − 2y = 10.
- Subtract the first from the second: y = 20. Then x = 10 + 2(20) = 50.
- **Answer: Nuri is 50 and Sonu is 20.**

**Trap:** adding or subtracting the years to only one person. Both ages move by the same number of years.

## Type 7: Fraction problem (3 marks)

> A fraction becomes 9/11 if 2 is added to both the numerator and the denominator. If 3 is added to both, it becomes 5/6. Find the fraction.

- Let the fraction be x/y.
- (x + 2)/(y + 2) = 9/11 gives 11x − 9y = −4.
- (x + 3)/(y + 3) = 5/6 gives 6x − 5y = −3.
- Multiply the first by 5 and the second by 9: 55x − 45y = −20 and 54x − 45y = −27. Subtract: x = 7.
- Then 6(7) − 5y = −3, so y = 9.
- **Answer: 7/9.** Check: 9/11 and 10/12 = 5/6.

## Type 8: Taxi fare (3 marks)

> A taxi charges a fixed amount plus a charge per km. For 10 km the fare is ₹105 and for 15 km it is ₹155. Find the fixed charge, the charge per km, and the fare for 25 km.

- Let the fixed charge be ₹x and the charge per km be ₹y.
- x + 10y = 105 and x + 15y = 155.
- Subtract: 5y = 50, so y = 10. Then x = 105 − 100 = 5.
- Fare for 25 km = 5 + 25 × 10 = ₹255.
- **Answer: fixed ₹5, ₹10 per km, ₹255 for 25 km.**

**Try it:** 2 pencils and 3 erasers cost ₹9; 4 pencils and 6 erasers cost ₹18. Can you find the price of one pencil? *No: 2/4 = 3/6 = 9/18, so the lines coincide and there are infinitely many answers.*

## One-minute revision

- Compare a₁/a₂, b₁/b₂, c₁/c₂ before you solve anything.
- "Infinitely many" needs all three ratios equal; "no solution" needs the first two equal and the third different.
- Pick elimination when a coefficient is easy to match; pick substitution when a variable has coefficient 1.
- Word problems: define both variables in words, write two equations, solve, then answer in a sentence with units.
- Always check your pair in both original equations.

## FAQ

**Which methods are in the current syllabus?**
The rationalised NCERT book teaches the graphical method, substitution and elimination. Cross-multiplication and "equations reducible to linear form" were removed, so practise the three methods used in this post.

**How many marks does this chapter carry?**
It sits in the Algebra unit of CBSE Class 10 Maths. Expect a 1-mark ratio question and a 2- or 3-mark word problem in most papers.
