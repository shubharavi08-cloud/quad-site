Chapter 7 of CBSE Class 10 Maths, *Coordinate Geometry*, is short and very scoring. In the rationalised NCERT book it has only two tools: the **distance formula** and the **section formula** (with the midpoint as a special case). Almost every board question is one of six patterns built from those two. Marks are lost on **sign errors with negative coordinates**, on **mixing up the ratio m : n**, and on **not writing the formula before substituting**.

## The two formulas you must know

- **Distance** between P(x₁, y₁) and Q(x₂, y₂): PQ = √[(x₂ − x₁)² + (y₂ − y₁)²]
- **Section formula**: the point dividing PQ internally in the ratio m : n is ((m x₂ + n x₁)/(m + n), (m y₂ + n y₁)/(m + n))
- **Midpoint** (ratio 1 : 1): ((x₁ + x₂)/2, (y₁ + y₂)/2)

A memory hook for the section formula: **m goes with the far point** (x₂, y₂), **n goes with the near point** (x₁, y₁). Cross-multiply, never straight-multiply.

## Type 1: Distance between two points

> Find the distance between (2, 3) and (4, 1).

- PQ = √[(4 − 2)² + (1 − 3)²] = √(4 + 4) = √8 = **2√2 units**

**Marking tip:** write the formula line first, then the substituted line. If the final arithmetic slips, the first two lines still earn the method marks.

## Type 2: A point on an axis that is equidistant

> Find the point on the x-axis which is equidistant from (2, −5) and (−2, 9).

- Any point on the x-axis is P(x, 0). Set PA² = PB² (squaring removes the roots).
- (x − 2)² + (0 + 5)² = (x + 2)² + (0 − 9)²
- x² − 4x + 4 + 25 = x² + 4x + 4 + 81
- −8x = 56, so x = −7. The point is **(−7, 0)**.

**Common mistake:** writing (0 − (−5))² as (−5)² and then forgetting it is +25. Brackets around every negative coordinate prevent this.

## Type 3: Prove the shape (square, rhombus, right triangle)

> Show that A(1, 7), B(4, 2), C(−1, −1) and D(−4, 4) are the vertices of a square.

- AB² = 3² + (−5)² = 34, BC² = (−5)² + (−3)² = 34
- CD² = (−3)² + 5² = 34, DA² = 5² + 3² = 34
- Diagonals: AC² = (−2)² + (−8)² = 68, BD² = (−8)² + 2² = 68
- All four sides are equal **and** the diagonals are equal, so ABCD is a **square**.

**Marking tip:** four equal sides only prove a rhombus. The equal diagonals are what make it a square, so always write both lines and the conclusion sentence.

## Type 4: Section formula, ratio given

> Find the coordinates of the point which divides the join of (−1, 7) and (4, −3) in the ratio 2 : 3.

- m = 2, n = 3, (x₁, y₁) = (−1, 7), (x₂, y₂) = (4, −3)
- x = (2 × 4 + 3 × (−1)) / 5 = (8 − 3)/5 = 1
- y = (2 × (−3) + 3 × 7) / 5 = (−6 + 21)/5 = 3
- The point is **(1, 3)**.

**Points of trisection** use the same formula twice, with ratios 1 : 2 and 2 : 1. For (4, −1) and (−2, −3) they are **(2, −5/3)** and **(0, −7/3)**.

## Type 5: Find the ratio in which an axis divides a segment

> Find the ratio in which the y-axis divides the line segment joining (5, −6) and (−1, −4). Also find the point of intersection.

- Take the ratio as k : 1. On the y-axis the x-coordinate is 0.
- x = (k × (−1) + 1 × 5)/(k + 1) = 0, so −k + 5 = 0 and **k = 5**. The ratio is **5 : 1**.
- y = (5 × (−4) + 1 × (−6))/6 = −26/6 = −13/3
- The point is **(0, −13/3)**.

**Why k : 1?** One unknown is easier than two. Whatever k comes out as, the ratio is k : 1.

## Type 6: Parallelogram, find the missing coordinates

> If (1, 2), (4, y), (x, 6) and (3, 5) are the vertices of a parallelogram taken in order, find x and y.

- The diagonals of a parallelogram bisect each other, so the midpoint of AC = the midpoint of BD.
- ((1 + x)/2, (2 + 6)/2) = ((4 + 3)/2, (y + 5)/2)
- 1 + x = 7, so **x = 6**; 8 = y + 5, so **y = 3**.

**Marking tip:** state the property ("diagonals bisect each other") in words. That one sentence is often a separate mark.

## A four-step routine for every question

1. Write the points as (x₁, y₁) and (x₂, y₂) and label them before you start.
2. Put every negative coordinate in brackets.
3. For "equidistant" questions, compare squares (PA² = PB²) instead of square roots.
4. Check your answer: a midpoint should sit between the two points, and a point on the x-axis must have y = 0.

## FAQ

**Is the area of a triangle formula still in Chapter 7?**
No. The "area of a triangle" section was removed from the rationalised NCERT Class 10 book, so current questions use only the distance and section formulas. Always check the latest CBSE syllabus and sample paper for your exam year.

**Can I leave the answer as √8?**
Simplify surds where you can (√8 = 2√2) and write "units". It is a small step that examiners expect.

**What is the fastest MCQ check?**
Substitute the options. If a question says the point lies on the x-axis, any option with y ≠ 0 is wrong straight away.
